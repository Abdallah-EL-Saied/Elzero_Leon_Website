## 📖 About the Project  
**Leon** is a minimal, clean agency-style template built with **HTML & CSS**.  
This project is part of my practice and application of lessons from **Elzero Web School**.  
The design emphasizes simplicity, clear layout, and presentation of services, portfolio, about, and contact sections.

Live demo:  
🔗 [Leon Website Live](https://abdallah-el-saied.github.io/Elzero_Leon_Website/)  

---

## 🛠️ Built With  
- **HTML5** for structure and semantics  
- **CSS3** for layout, styling, and responsive design  

---

## 📂 Main Sections & Features  

Here are the key parts of the template that you’ll find:

| Section     | Description |
|--------------|-------------|
| **Hero / Intro** | A welcoming title “We are Leon – Super Creative & Minimal Agency Web Template” with subtext and call to action. |
| **Services** | Showcases services like Graphic Design, UI & UX, Web Design, Web Development with brief descriptions. |
| **Portfolio** | A gallery of projects (images + captions) to showcase creative work. |
| **About** | A section with a short paragraph about the agency/vision (“Less is more”) and some descriptive text. |
| **Contact** | Contact information: email, “Find us on social networks” prompt, etc. |
| **Footer** | Copyright notice, site name, year. |

---

## 📚 Lessons Learned  
- How to build a multi-section one-page layout  
- Semantic HTML structure (sections, headings, paragraphs)  
- Styling multiple sections cohesively with CSS  
- Aligning images and content in portfolio & service sections  
- Organizing “About” and “Contact” sections cleanly
